## Project này là gì?

`ThayCang` là workspace Java Eclipse cho buổi học với thầy Cang. Root có `.project`, `.classpath`, `.settings` — đúng lab Eclipse, khác repo `java` gắn IntelliJ. Không README. Toàn bộ source dưới `src`, chia theo buổi chứ không theo chủ đề tự đặt.

`buoi01` là bài nhập môn (`bai3` tới `bai8`). `buoi2` có `Date`, `Diem`, `PhanSo`, `CanBo` và các class `SD*` để chạy thử. `buoi3` có `DoanThang`, `Gach`, `SinhVien`. `buoi4` đa hình `DVat` / `Bo` / `Ga` / `Heo` và `SinhVienCNTT`. `buoi5` hóa đơn: `HangHoa`, `HoaDon`, `KhachHang`, `KhachHangVIP`, `ChiTiet`. `KTGK` có `BNhan`; `KTCK` dày hơn với `BNCovid`, `BNhan`, `CNguoi`, `CThu`, `GDich`, `GDichTTe`, `QuocGia`, `QuocGiaPT`. `QuanLiCV` gắn class vào hồ sơ: `CanBo`, `HocVan`, `KinhNghiemLamViec`, `HoatDong`, `GiaiThuong`.

Đây là nhật ký nộp bài theo buổi, không phải lộ trình số bài TITV.

## Vì sao làm project này?

Trên lab, một buổi một package giúp nộp đúng hạn và ôn đúng phạm vi trước kiểm tra. Khi tới `KTGK`/`KTCK`, mở lại `buoi2`–`buoi5` nhanh hơn lục máy phòng máy. `QuanLiCV` là chỗ mình gắn class đã học vào bài “hồ sơ / hoạt động / học vấn”.

## Vấn đề hoặc mục tiêu cần giải quyết

Mục tiêu là hoàn thành bài tuần, làm kiểm tra, và trong `QuanLiCV` mô hình hóa thực thể CV bằng Java thuần. Không đặt mục tiêu Swing đẹp, JDBC hay deploy. Tiêu chí thành công: từng `buoi*` biên dịch trên Eclipse.

## Vai trò của tôi trong project

Mình tự viết bài trong từng `buoi*`, phần kiểm tra và `QuanLiCV`. Đây là repo cá nhân theo tiến độ môn.

## Kết quả và những gì học được

Kết quả là chuỗi bài từ `PhanSo` tới hóa đơn và quản lý CV. So với repo `java` (tự chia OOP/UI trên IntelliJ), repo này dạy kỷ luật “một buổi một package” và class `SD*` để test nhanh. Thiếu README vẫn là điểm yếu — bài này liệt kê đúng tên folder. Repo: https://github.com/human6004/ThayCang
